🏗️ Plataforma Java: Arquitetura e Evolução

🕐 20/11/2025 22:40:47 👨‍💻 @rafaelsantos
📚 Sobre: Esta seção explora a arquitetura e evolução da plataforma Java, incluindo a era J2SE, J2EE e J2ME, e como a plataforma se desenvolveu para atender diferentes necessidades de mercado.

🎯 Visão Geral

A plataforma Java evoluiu significativamente desde seu lançamento inicial. Durante a era J2 (Java 2), a plataforma foi dividida em três edições distintas para atender diferentes necessidades: J2SE para aplicações desktop, J2EE para aplicações empresariais e servidores, e J2ME para dispositivos móveis e embarcados.

🔑 As Três Edições da Plataforma Java

💻

J2SE (Java 2 Standard Edition)

A edição padrão para desenvolvimento de aplicações desktop e cliente. Incluía as bibliotecas fundamentais, JVM, e ferramentas de desenvolvimento básicas.

🏢

J2EE (Java 2 Enterprise Edition)

A edição empresarial para desenvolvimento de aplicações server-side complexas. Incluía servlets, JSP, EJB, JMS, e outras tecnologias empresariais.

📱

J2ME (Java 2 Micro Edition)

A edição para dispositivos móveis e embarcados com recursos limitados. Incluía perfis como CLDC (Connected Limited Device Configuration) e MIDP (Mobile Information Device Profile).

🔄

Evolução e Unificação

Com o tempo, a nomenclatura mudou de J2 para Java SE, Java EE e Java ME, e posteriormente Java EE foi transferido para a Eclipse Foundation, tornando-se Jakarta EE.
