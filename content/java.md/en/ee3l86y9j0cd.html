📜 Java History

🕐 20/11/2025 22:40:47 👨‍💻 @rafaelsantos
📚 About: This section explores the rich history of Java, from its conception at Sun Microsystems to its evolution as one of the world's most important programming languages.

🎯 Overview

Java's history is a fascinating journey that began in the early 1990s at Sun Microsystems. This section covers the major milestones, events, and transformations that shaped Java over the years.

🔑 Important Milestones

🌱

Conception and Early Development

The Green project at Sun Microsystems, led by James Gosling, which resulted in the creation of Java. Originally called "Oak", the language was renamed to Java and publicly released in 1995.

🚀

Launch and Popularization

The release of JDK 1.0 in 1996 marked the beginning of the Java era. The promise of "write once, run anywhere" revolutionized software development.

🏢

Enterprise Era

The division into J2SE, J2EE, and J2ME allowed Java to serve different needs: desktop, server, and mobile/embedded devices.

🔄

Modernization and Evolution

With the accelerated release cycle and LTS versions, Java continues to evolve with new features like lambdas, streams, modules, and much more.
