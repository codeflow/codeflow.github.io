# 🚀 Expand OS Content and Improve Welcome UX

## 📋 Summary

This PR delivers new Operating Systems content in the Threads and Concurrency track, updates release automation/rules alignment, and improves the welcome experience with a latest-content carousel and refined diagram spacing behavior.

## ✨ Features Added

### 1. New OS Content
- Added **Threading Models** page in English.
- Covered many-to-one, one-to-one, and many-to-many threading models.
- Included mapping guidance and practical scheduler-oriented examples.

### 2. Welcome "Latest Content" Carousel
- Added carousel section before Content Statistics.
- Displays the latest 10 posts with square cards, short descriptions, and `Read more...` links.
- Uses right-aligned icon-style navigation arrows (`◀` / `▶`) consistent with BlueSky visual style.

### 3. Release and Learn Flow Alignment
- `/learn` flow includes `/update-release` as a mandatory final step.
- Release generation is aligned with `template-release.md`.
- Welcome/feed update rules enforce 10-item limit for timeline + carousel (`updates.json`).
