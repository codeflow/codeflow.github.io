# 🚀 Release Notes - Operating Systems

## 📊 Overview

This release expands the Operating Systems learning track with a new Threads and Concurrency page on thread lifecycle control and synchronization patterns, while also improving the welcome carousel experience on mobile devices.

- Includes synchronization-focused examples (mutex + condition variables) and worker-pool style execution patterns.
