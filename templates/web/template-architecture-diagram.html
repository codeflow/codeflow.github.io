🧩 Como usar

  • Estrutura: use a classe arch-diagram diretamente (sem .app-card - o .arch-diagram__inner já fornece a caixa externa).
  • Caixas: cada camada é um .arch-diagram__box.
  • Setas: use .arch-diagram__arrow entre as caixas, sempre com <span class="arch-diagram__arrow-line"></span> dentro.
  • Múltiplas colunas: adicione múltiplos .arch-diagram__stack dentro de .arch-diagram__inner para ter colunas lado a lado.
  • Legenda: .arch-diagram__caption fica no canto inferior direito da caixa externa.
