📋 Basic Structure

This is a basic template that demonstrates the minimum structure needed to create a new HTML page in Codeflow. All pages should follow this structure to maintain visual and functional consistency.

🔧 Included Components

  • Sidebar Menu: Navigation menu with search and content tree
  • Header: Header with page title and language selector
  • Content Area: Main area where page content is displayed
  • Scripts: All scripts necessary for full functionality

📝 How to Use

  1. Copy this template to create a new page
  2. Update metadata (title, description, etc.)
  3. Add your content inside the .content-container div
  4. Adjust relative paths of resources (CSS, JS, images) as needed
💡 Tip: Always maintain the layout structure (sidebar, header, content) to ensure the menu and other functionalities work correctly.
