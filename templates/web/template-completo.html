📝 Components Summary

Available Components

  • Titles: h1, h2, h3 with automatic styles
  • Forms: inputs, selects, textareas, buttons
  • Tables: thead, tbody, tfoot with zebra styles
  • Cards: .app-card to group content
  • Boxes: .info-box, .highlight-box, .success-box
  • Code: inline code and blocks with syntax highlighting
  • Timeline: .timeline and .timeline-item
  • Icons: .icon-section and .emoji-large
