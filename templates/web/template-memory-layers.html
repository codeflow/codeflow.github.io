📌 Memory Layers Template

📚 Sobre: Este template demonstra como representar camadas empilhadas (estilo regiões de memória) usando caixas sem setas, com uma legenda no canto inferior direito da caixa externa.

💾 Exemplo: Layout de Memória

Diagrama mostrando as diferentes regiões de memória empilhadas:

Stack (High Memory)
Local variables, function calls
Heap
Dynamic memory allocation
Data Segment
Global and static variables
Code Segment (Low Memory)
Program instructions
Memory Layout

📊 Exemplo: Camadas de Sistema

Diagrama mostrando camadas de sistema operacional:

User Space
Applications, user programs
System Libraries
Shared libraries, system calls
Kernel Space
Device drivers, kernel modules
Hardware
CPU, memory, I/O devices
Operating System Layers

🧩 Como usar

  • Estrutura: use a classe memory-layers diretamente (sem .app-card - o .memory-layers__inner já fornece a caixa externa).
  • Camadas: cada camada é um .memory-layers__layer.
  • Cabeçalho: use .memory-layers__layer-header para o título da camada.
  • Conteúdo: use .memory-layers__layer-content para o conteúdo descritivo da camada.
  • Destaque: use memory-layers__layer--accent na primeira e última camada para dar ênfase.
  • Legenda: .memory-layers__caption fica no canto inferior direito da caixa externa.
  • Sem setas: este componente não usa setas - as camadas são simplesmente empilhadas.

📝 Exemplo de Código HTML

HTML 
<div class="memory-layers">
  <div class="memory-layers__inner">
    <div class="memory-layers__layer memory-layers__layer--accent">
      <div class="memory-layers__layer-header">Stack (High Memory)</div>
      <div class="memory-layers__layer-content">Local variables, function calls</div>
    </div>
    <div class="memory-layers__layer">
      <div class="memory-layers__layer-header">Heap</div>
      <div class="memory-layers__layer-content">Dynamic memory allocation</div>
    </div>
    <div class="memory-layers__layer memory-layers__layer--accent">
      <div class="memory-layers__layer-header">Code Segment (Low Memory)</div>
      <div class="memory-layers__layer-content">Program instructions</div>
    </div>
    <div class="memory-layers__caption">Memory Layout</div>
  </div>
</div>

⚡ Quando usar

  • Regiões de memória: Stack, Heap, Data Segment, Code Segment
  • Camadas de sistema: User Space, Kernel Space, Hardware
  • Hierarquias estáticas: Estruturas que não precisam de setas
  • Pilhas de memória: Visualização de stack frames
  • Camadas de abstração: Quando não há fluxo, apenas estrutura

🔄 Diferença entre os componentes

Architecture Diagram (Vertical): Use quando precisa mostrar setas entre camadas (ex: Application → Framework → OS).

Memory Layers: Use quando precisa mostrar camadas empilhadas SEM setas (ex: Stack, Heap, Data, Code). Ideal para regiões de memória ou estruturas estáticas.
