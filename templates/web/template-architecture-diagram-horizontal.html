📌 Architecture Diagram Horizontal Template

📚 Sobre: Este template demonstra como representar uma arquitetura horizontal usando caixas + setas (fluxo da esquerda para a direita), com uma legenda no canto inferior direito da caixa externa.

🔄 Exemplo: Linha Única (Single Row)

Diagrama horizontal com uma única linha de caixas conectadas da esquerda para a direita:

Client Request
Load Balancer
Application Server
Database
Request Flow

📊 Exemplo: Múltiplas Linhas (Multiple Rows)

Diagrama horizontal com múltiplas linhas empilhadas verticalmente, cada uma representando um fluxo diferente:

User Input
Validation
Processing
Data Fetch
API Call
Response
Cache Check
Storage
Data Processing Pipeline

🧩 Como usar

  • Estrutura: use a classe arch-diagram arch-diagram--horizontal no elemento raiz (sem .app-card - o .arch-diagram__inner já fornece a caixa externa).
  • Caixas: cada elemento é um .arch-diagram__box.
  • Setas: use .arch-diagram__arrow arch-diagram__arrow--horizontal entre as caixas, sempre com <span class="arch-diagram__arrow-line arch-diagram__arrow-line--horizontal"></span> dentro.
  • Stack horizontal: use .arch-diagram__stack arch-diagram__stack--horizontal para criar uma linha horizontal de caixas.
  • Múltiplas linhas: adicione múltiplos .arch-diagram__stack arch-diagram__stack--horizontal dentro de .arch-diagram__inner para ter linhas empilhadas verticalmente.
  • Legenda: .arch-diagram__caption fica no canto inferior direito da caixa externa.
  • Responsivo: em mobile, as linhas horizontais se empilham verticalmente automaticamente.

📝 Exemplo de Código HTML

HTML 
<div class="arch-diagram arch-diagram--horizontal">
  <div class="arch-diagram__inner">
    <div class="arch-diagram__stack arch-diagram__stack--horizontal">
      <div class="arch-diagram__box arch-diagram__box--accent">Client Request</div>
      <div class="arch-diagram__arrow arch-diagram__arrow--horizontal">
        <span class="arch-diagram__arrow-line arch-diagram__arrow-line--horizontal"></span>
      </div>
      <div class="arch-diagram__box">Load Balancer</div>
      <div class="arch-diagram__arrow arch-diagram__arrow--horizontal">
        <span class="arch-diagram__arrow-line arch-diagram__arrow-line--horizontal"></span>
      </div>
      <div class="arch-diagram__box arch-diagram__box--accent">Database</div>
    </div>
    <div class="arch-diagram__caption">Request Flow</div>
  </div>
</div>

⚡ Quando usar

  • Fluxos de requisição: Client → Server → Database
  • Pipelines de dados: Input → Processing → Output
  • Processos sequenciais: Step 1 → Step 2 → Step 3
  • Fluxos de trabalho: Start → Process → End
  • Arquiteturas de rede: Frontend → API → Backend → Database

🔄 Diferença entre Vertical e Horizontal

Vertical (architecture-diagram): Use para representar camadas de sistema, hierarquias, ou estruturas em camadas (ex: Application Layer → GTK → GDK → OS).

Horizontal (architecture-diagram-horizontal): Use para representar fluxos, pipelines, ou processos sequenciais que fluem da esquerda para a direita (ex: Request → Load Balancer → Server → Database).
