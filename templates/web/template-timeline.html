    📅 Timeline Template

    This template demonstrates how to use the timeline component in the Codeflow BlueSky theme. The timeline is ideal for showing chronological events, version history, updates or any temporal sequence.

    ✨ New Design: The timeline now has a modern design with cards for each event, animated circles as markers and hover effect for better interactivity.

    📋 Basic Timeline

    Event 1 - January 2025

    First timeline event. This is an example of how to add content to each timeline item. Each item is now displayed as a card with border and subtle shadow.

    Event 2 - February 2025

    Second timeline event. Each item can contain formatted text, links and other HTML elements. The modern design makes the timeline more visually attractive.

    Event 3 - March 2025

    Third timeline event. The timeline uses a vertical line on the left with animated circles as markers for each event, creating a richer visual experience.

    Event 4 - April 2025

    Fourth timeline event. Spacing between items is automatic and responsive. Hover over items to see the hover effect.

    📝 Example de Code HTML

    HTML 
    <div class="timeline">
    <div class="timeline-item">
        <strong>Event 1 - January 2025</strong>
        <p>First event description. Use paragraphs for longer content.</p>
    </div>
    <div class="timeline-item">
        <strong>Event 2 - February 2025</strong>
        <p>Second event description. Each item is displayed as a styled card.</p>
    </div>
    <div class="timeline-item">
        <strong>Event 3 - March 2025</strong>
        <p>Third event description. The modern design includes animated circles and hover effect.</p>
    </div>
</div>
    💡 Tip: The timeline uses the classes .timeline e .timeline-item from the BlueSky theme. Each timeline item is automatically styled as a card with:
    • Animated circle as marker on the vertical line
    • Blue left border for highlight
    • Subtle shadow for depth
    • Hover effect for interactivity
    • Animação de pulso nos marcadores
    ⚠️ Important: The timeline is ideal for showing events in chronological order. The most recent events usually appear at the top or bottom, depending on the desired order.
