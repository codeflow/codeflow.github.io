🏛️ Era J2SE, J2EE, J2ME: A Divisão da Plataforma Java

📅 Período: 1998 - 2006
🏢 Empresa: Sun Microsystems
🎯 Versões: Java 2 Platform (J2SE 1.2 - 1.5, J2EE 1.2 - 1.5, J2ME 1.0 - 3.0)

🎯 O Que Foi a Era J2?

A Era J2SE, J2EE, J2ME marcou um momento crucial na história do Java, quando a Sun Microsystems reorganizou a plataforma Java em três edições distintas para atender diferentes necessidades de mercado. Esta divisão ocorreu com o lançamento do Java 2 Platform em dezembro de 1998.

💡 Mudança de Nomenclatura: Com o Java 2, a Sun mudou a nomenclatura de "JDK" para "J2SE" (Java 2 Platform, Standard Edition), criando também as edições Enterprise (J2EE) e Micro (J2ME).

📦 As Três Edições da Plataforma Java 2

O Java 2 Platform foi dividido em três edições principais:

🖥️ J2SE
Java 2 Platform, Standard Edition
Para aplicações desktop e servidor
🏢 J2EE
Java 2 Platform, Enterprise Edition
Para aplicações empresariais e corporativas
📱 J2ME
Java 2 Platform, Micro Edition
Para dispositivos embarcados e móveis

🖥️ J2SE - Java 2 Platform, Standard Edition

O J2SE era a edição padrão da plataforma Java, destinada ao desenvolvimento de aplicações desktop, applets e aplicações servidor de pequeno a médio porte.

Características Principais do J2SE

  • ✅ Core Java - Linguagem Java e bibliotecas fundamentais
  • ✅ Swing - Framework de interface gráfica (substituiu AWT)
  • ✅ Collections Framework - Estruturas de dados modernas
  • ✅ JavaBeans - Componentes reutilizáveis
  • ✅ JDBC - Acesso a bancos de dados
  • ✅ RMI - Invocação remota de métodos
  • ✅ JNI - Interface nativa Java

Versões do J2SE

Versão Data de Lançamento Principais Novidades

J2SE 1.3 Maio 2000 HotSpot JVM, JavaSound, RMI sobre IIOP
J2SE 1.4 Fevereiro 2002 Assertions, Regular Expressions, NIO, Logging API

🏢 J2EE - Java 2 Platform, Enterprise Edition

O J2EE foi projetado para o desenvolvimento de aplicações empresariais de grande escala, incluindo servidores de aplicação, sistemas distribuídos e aplicações web complexas.

Características Principais do J2EE

  • 🏗️ Servlets & JSP - Desenvolvimento web
  • 💼 EJB (Enterprise JavaBeans) - Componentes de negócio distribuídos
  • 📧 JavaMail - Envio e recebimento de e-mails
  • 💾 JMS (Java Message Service) - Mensageria assíncrona
  • 🔐 JTA (Java Transaction API) - Gerenciamento de transações
  • 🌐 JNDI (Java Naming and Directory Interface) - Serviços de diretório
  • 📡 RMI-IIOP - Integração com CORBA
  • 🔌 JCA (Java Connector Architecture) - Integração com sistemas legados

Arquitetura J2EE

J2EE 1.3 Setembro 2001 Servlets 2.3, JSP 1.2, EJB 2.0, JMS 1.0.2

Servidores de Aplicação J2EE

Principais servidores de aplicação que implementavam a especificação J2EE:

  • 🌐 BEA WebLogic - Um dos mais populares
  • ☕ IBM WebSphere - Solução enterprise da IBM
  • 🐱 Apache Tomcat - Container web (Servlets/JSP)
  • 💀 JBoss Application Server - Open source
  • ☀️ Sun Java System Application Server - Solução da Sun
  • 🔷 Oracle Application Server - Solução Oracle

📱 J2ME - Java 2 Platform, Micro Edition

O J2ME foi desenvolvido para dispositivos com recursos limitados, como telefones celulares, PDAs, set-top boxes e outros dispositivos embarcados.

Características Principais do J2ME

  • 📱 CLDC (Connected Limited Device Configuration) - Para dispositivos com pouca memória
  • 📲 MIDP (Mobile Information Device Profile) - Para telefones celulares
  • 🖥️ CDC (Connected Device Configuration) - Para dispositivos com mais recursos
  • 🎮 J2ME Games - Desenvolvimento de jogos móveis
  • 📡 Wireless APIs - Comunicação sem fio

Configurações e Perfis do J2ME

Configuração/Perfil Descrição Dispositivos Alvo

MIDP Mobile Information Device Profile Telefones celulares Java (Java ME)
CDC Connected Device Configuration Set-top boxes, dispositivos embarcados
PersonalJava Perfil para dispositivos pessoais PDAs avançados, dispositivos portáteis

🎯 Por Que a Divisão em Três Edições?

A divisão do Java em três edições foi motivada por várias razões:

  • 🎯 Foco Específico - Cada edição atende a um mercado diferente
  • 📦 Otimização - J2ME otimizado para dispositivos com poucos recursos
  • 🏢 Mercado Enterprise - J2EE com APIs específicas para grandes corporações
  • 💼 Licenciamento - Diferentes modelos de licenciamento para cada edição
  • 🔧 Manutenção - Facilita a evolução independente de cada plataforma

📈 Impacto no Mercado

A era J2 teve um impacto significativo no mercado de desenvolvimento:

🏢 Enterprise
J2EE dominou o mercado de aplicações empresariais, competindo com .NET
📱 Mobile
J2ME foi amplamente adotado em telefones celulares, especialmente Nokia e Motorola
🖥️ Desktop
J2SE continuou sendo a base para desenvolvimento desktop e servidor

🔄 Transição: De J2 para Java SE/EE/ME

Em 2006, a Sun Microsystems simplificou a nomenclatura, removendo o "2" dos nomes:

Nome Antigo (J2) Nome Novo (2006+) Versão de Transição
J2SE 5.0 Java SE 5 2004
J2SE 6 Java SE 6 2006
J2EE 5.0 Java EE 5 2006
J2ME Java ME 2006

💻 Exemplo: Desenvolvimento J2EE

Um exemplo básico de um Servlet J2EE:

import javax.servlet.*;
import javax.servlet.http.*;
import java.io.*;

public class HelloServlet extends HttpServlet {
    public void doGet(HttpServletRequest request, 
                     HttpServletResponse response)
            throws ServletException, IOException {
        response.setContentType("text/html");
        PrintWriter out = response.getWriter();
        out.println("<html><body>");
        out.println("<h1>Hello J2EE World!</h1>");
        out.println("</body></html>");
    }
}

📱 Exemplo: Desenvolvimento J2ME (MIDlet)

Um exemplo básico de um MIDlet J2ME:

import javax.microedition.midlet.*;
import javax.microedition.lcdui.*;

public class HelloMIDlet extends MIDlet {
    private Display display;
    
    public void startApp() {
        display = Display.getDisplay(this);
        Form form = new Form("Hello J2ME");
        form.append("Hello, Mobile World!");
        display.setCurrent(form);
    }
    
    public void pauseApp() {}
    public void destroyApp(boolean unconditional) {}
}

🌟 Legado da Era J2

A era J2 deixou um legado importante:

  • 🏗️ Arquitetura Enterprise - Estabeleceu padrões para aplicações corporativas
  • 📱 Java Mobile - Popularizou Java em dispositivos móveis
  • 🌐 Servidores de Aplicação - Criou um ecossistema robusto de servidores
  • 📚 Especificações - Estabeleceu muitas especificações que ainda são usadas hoje
  • 💼 Mercado - Consolidou Java como plataforma enterprise

📊 Estatísticas: No auge da era J2, o J2EE era usado por mais de 70% das empresas Fortune 500 para desenvolvimento de aplicações empresariais, e o J2ME estava presente em mais de 1 bilhão de dispositivos móveis.

🔄 Evolução Pós-J2

Após a era J2, as plataformas evoluíram:

  • ☕ Java SE - Continuou evoluindo com novas versões (6, 7, 8, 9+)
  • 🏢 Java EE - Evoluiu para Jakarta EE (após doação para Eclipse Foundation)
  • 📱 Java ME - Evoluiu para Java ME Embedded e outras variantes
  • ☁️ Cloud - Surgiram frameworks modernos como Spring Boot, Quarkus, Micronaut
💭 Reflexão: A era J2SE, J2EE, J2ME foi fundamental para estabelecer Java como uma plataforma completa e abrangente, capaz de atender desde dispositivos móveis até grandes sistemas empresariais. Esta divisão estratégica permitiu que Java dominasse múltiplos mercados simultaneamente.
