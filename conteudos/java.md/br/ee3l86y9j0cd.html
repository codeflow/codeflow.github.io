📜 História do Java

📚 Sobre: Esta seção explora a rica história do Java, desde sua concepção na Sun Microsystems até sua evolução como uma das linguagens de programação mais importantes do mundo.

🎯 Visão Geral

A história do Java é uma jornada fascinante que começou no início dos anos 1990 na Sun Microsystems. Esta seção cobre os principais marcos, eventos e transformações que moldaram o Java ao longo dos anos.

🔑 Marcos Importantes

🌱

Concepção e Desenvolvimento Inicial

O projeto Green na Sun Microsystems, liderado por James Gosling, que resultou na criação do Java. Originalmente chamado de "Oak", a linguagem foi renomeada para Java e lançada publicamente em 1995.

🚀

Lançamento e Popularização

O lançamento do JDK 1.0 em 1996 marcou o início da era Java. A promessa de "escreva uma vez, execute em qualquer lugar" revolucionou o desenvolvimento de software.

🏢

Era Empresarial

A divisão em J2SE, J2EE e J2ME permitiu que o Java atendesse diferentes necessidades: desktop, servidor e dispositivos móveis/embarcados.

🔄

Modernização e Evolução

Com o ciclo de lançamento acelerado e versões LTS, o Java continua evoluindo com novos recursos como lambdas, streams, módulos e muito mais.
